# Study Abroad Atlas

An interactive guide for Indian students planning a master's or bachelor's abroad: admission steps, visa documents, universities and tuition, a first-year cost calculator, a country comparison, consultancies by city, and safe work-abroad routes. Covers the USA, UK, Scotland, Germany, Canada, Australia, Ireland, New Zealand, France, the Netherlands and Switzerland.

It is a single static file (`index.html`) with no build step, so it runs on GitHub Pages as-is.

Figures were checked against official and cited sources in October 2026; fees and visa rules change often, so confirm on the official sites before paying anything.
