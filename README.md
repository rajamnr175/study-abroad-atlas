# Study Abroad Atlas

An interactive guide for Indian students planning a master's abroad. Covers the USA, UK, Scotland, Germany, Canada, Australia, Ireland, New Zealand, France, the Netherlands and Switzerland.

- **Find my fit**: set a family budget and priorities (cost, post-study work, short course, easier visa) and see which countries fit, ranked, with each first-year cost range drawn against your budget.
- **Country guide**: one scrolling dossier per country: key facts, a month-by-month plan from your intake, admission and visa steps, a document checklist that remembers your ticks, universities and tuition, a first-year cost calculator, the current rules and sources.
- **2027 intake / today's rules** toggle, so announced increases (UK maintenance funds, the 18-month Graduate route, Germany's blocked account) show up in every figure.
- **Compare** first-year costs across all countries, with your budget line.
- **Process & consultancies**: the full admission-to-visa process and consultancies by city.
- **Jobs abroad**: safe, legal work-abroad routes and how to spot recruitment scams.
- **Ask a question**: a small helper that answers from the page's own data (no AI service).
- Editable exchange rates (ECB reference rates, 23 Oct 2026); every figure updates.

It is a single static file (`index.html`) with no build step, so it runs on GitHub Pages as-is.

Figures were checked against official and cited sources in October 2026; fees and visa rules change often, so confirm on the official sites before paying anything.
